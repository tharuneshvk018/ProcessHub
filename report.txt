2.3 RESEARCH-INFORMED PRODUCT IMPROVEMENT PLAN
----------------------------------------------
Based on competitive analysis of Jira Service Management, Camunda, GLPI, and facilities maintenance systems:
1. Dynamic Routing without Scheme Bloat:
   Overcome JSM's limitation where workflows bind to Issue Types rather than Request Types.
   ProcessHub implements a data-driven routing engine matching category, location, asset,
   and severity to designated supervisors and teams without requiring database schema alterations.
2. Unified State & Single Source of Truth:
   Overcome Camunda's "split-brain" vulnerability by anchoring the workflow state machine
   directly inside the core relational database transactions alongside the issue entity.
3. Explainable Progress for Users:
   Overcome legacy ticket opacity. Every issue computes an ExplainableProgress record detailing:
   Current Stage, Blocking Dependency (e.g. Finance Approval), Responsible Team, and Required Next Action.
4. Recurring-Issue Detection:
   Overcome generic CMMS isolation by correlating issues across Asset ID and Location Room/Building
   within a 90-day window, delivering actionable historical repair cards to technicians.
5. Strict Verification & Closure Gate:
   Prevent unauthorized self-verification by technicians; enforce independent verification
   by supervisor or reporter with captured completion notes and evidence.
